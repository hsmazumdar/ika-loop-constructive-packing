# Supplementary materials

Tables and figures that accompany the packing-memory study. The manuscript is not in this repository.

- `SUPPLEMENTARY_TABLES.docx` and `SUPPLEMENTARY_TABLES.pdf` — detailed tables
- `SUPPLEMENTARY_FIGURES.docx` and `SUPPLEMENTARY_FIGURES.pdf` — supplementary figures, captions under the images
- `figures/` — the same figures as separate image files
- `SUPPLEMENTARY_TABLES.md` and `CAPTIONS.md` — the same text in Markdown

Saved experiment runs used by these tables are in the experiment folders at the repository root. `REVIEWER_GUIDE.md` names the authoritative run for each experiment.
